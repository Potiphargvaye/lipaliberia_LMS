# LIPA Learning Management System (LMS)

> **Version:** v1.0.0
> **Status:** Under Active Development 🚧

## Overview

The **LIPA Learning Management System (LMS)** is a modern, secure, and scalable web-based learning platform developed specifically for the **Liberia Institute of Public Administration (LIPA)**.

The platform is designed to digitize and streamline learning, training, and academic administration by providing an integrated environment for students, instructors, and administrators. It enables course delivery, online learning, assessments, learner progress tracking, communication, and administrative management through a centralized system.

This repository contains the initial development version (**v1.0.0**) of the LIPA LMS.

---

# Project Objectives

The primary objectives of this project are to:

* Digitize the learning experience at LIPA.
* Provide centralized course management.
* Support online teaching and learning.
* Deliver assignments and online assessments.
* Track learner progress and performance.
* Improve communication between learners and instructors.
* Provide secure role-based access control.
* Support future growth through a scalable architecture.
